// Three characteristics

Pick the shape of your target

A part at the spec limit and a part just inside it are nearly the same part. Taguchi's quadratic loss reflects that: cost grows smoothly as output drifts from ideal, instead of jumping from $0 to scrap at the limit.

NIB

Nominal-Is-Best

L(y) = k(y − m)²
k = A₀ / Δ²

A target value is ideal and deviation either way costs money. Diameters, fill weights, voltages.

LIB

Larger-Is-Better

L(y) = k / y²
k = A₀ · m²

More is always better. Bond strength, tensile strength, efficiency, life to failure.

SIB

Smaller-Is-Better

L(y) = k · y²
k = A₀ / m²

Zero is ideal. Leak rate, wear, shrinkage, noise, contamination, wait time.

A₀ = cost to the customer or business when output reaches the tolerance / reference point (rework, warranty, give-away). Δ = tolerance half-width. m = target (NIB) or reference limit (LIB/SIB).

terminal / python
# install once
pip install numpy pandas matplotlib

# run the worked example (prints summaries, saves taguchi_example_python.png)
python taguchi_loss.py demo

# single part
python taguchi_loss.py nib --target 500 --delta 10 --A0 2.50 --y 506

# batch from your CSV, save the chart and per-part results
python taguchi_loss.py nib --target 500 --delta 10 --A0 2.50 \
    --csv example_data.csv --column fill_weight_g --save nib.png --export nib_results.csv

# or use it as a library
from taguchi_loss import NominalIsBest
nib = NominalIsBest(target=500, delta=10, A0=2.50)
print(nib.from_csv("example_data.csv", "fill_weight_g").summary())
R / RStudio
# from a terminal: run the worked example (saves taguchi_example_R.png)
Rscript taguchi_loss.R demo

# inside R or RStudio
source("taguchi_loss.R")
nib <- taguchi_calc("nib", target = 500, delta = 10, A0 = 2.50)
taguchi_eval(nib, 506)                                   # single part

b <- taguchi_from_csv(nib, "example_data.csv", "fill_weight_g")
print(b)                                                 # batch summary
taguchi_plot(nib, b)                                     # curve + losses
taguchi_export_csv(b, "nib_results.csv")

lib <- taguchi_calc("lib", m = 80, A0 = 400)
sib <- taguchi_calc("sib", m = 5,  A0 = 300)

Reading it: fill weight is fine, but re-centring the filler from 502.5 g to 500 g removes about 41% of its loss for free. Bond strength passes spec on every unit yet carries the largest cost — a capability problem that a pass/fail view hides.
