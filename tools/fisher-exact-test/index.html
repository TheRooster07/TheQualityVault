Fisher's Exact Test

Exact test of association for a 2 × 2 table of counts. Use it instead of the chi-square test when counts are small (any expected count below 5). Reports two-sided and one-sided p-values and the odds ratio.

Command line

Python needs the packages named on its download card; R uses base R. Both run the worked example with demo and accept your own CSV.

python fisher_exact.py demo
python fisher_exact.py --csv my_table.csv --cols Label Col1 Col2
Rscript fisher_exact.R
