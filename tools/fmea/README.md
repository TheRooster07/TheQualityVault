# FMEA Workbook — TheQualityVault.com

Process or Design FMEA worksheet: RPN (S × O × D), adjustable priority flag, before/after
action tracking, summary counts and an automatic RPN Pareto of the top 10 failure modes.

## Files
| File | What it is |
|---|---|
| FMEA_Workbook.xlsx | Tabs: How to Use, Example (completed Process FMEA, 8 failure modes), Blank Template (50 rows), Rating Scales (1–10 S/O/D guidance). No macros. |

Python and R versions are not provided for this tool — it is a structured worksheet rather than a statistical calculation.

## Priority rule
High if S ≥ 9 or RPN ≥ 200; Medium if RPN ≥ 100; otherwise Low. All three thresholds are editable.
Teams following the AIAG-VDA handbook should use its Action Priority table instead.
