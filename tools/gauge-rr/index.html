Command line

Python needs the packages named on its download card; R uses base R. Both run the worked example with demo and accept your own CSV.

python gauge_rr.py demo
python gauge_rr.py --csv my_study.csv --part part --operator operator --value measurement --tolerance 3.0 --save grr.png
Rscript gauge_rr.R

Notes

Study must be balanced. Study variation = 6 × SD. Interaction pooled when p ≥ alpha (default 0.05). In the Excel chart helper columns, N/A values are deliberate — they hide unused parts on the interaction chart.
