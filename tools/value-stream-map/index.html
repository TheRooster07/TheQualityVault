Value Stream Mapping Template

Record up to 12 process steps with cycle time, changeover, uptime, operators and inventory. Calculates takt time, bottleneck, inventory days, production lead time, value-added time and process cycle efficiency (PCE), draws the map with a timeline ladder, and plots line balance vs takt.
