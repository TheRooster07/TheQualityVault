# Value Stream Map (VSM) — TheQualityVault.com

Record up to 12 process steps with cycle time, changeover, uptime, operators and inventory.
Calculates takt time, bottleneck, inventory days, production lead time, value-added time and
process cycle efficiency (PCE), draws the map with a timeline ladder, and plots line balance vs takt.

## Files
| File | What it is |
|---|---|
| Value_Stream_Map.xlsx | Tabs: How to Use, Example (7-step bracket line, current state), Blank Template. No macros. |

Python and R versions are not provided — this is a mapping template rather than a statistical calculation.

## Example
Demand 920/day, 2 × 27,600 s → takt 60 s. CNC drill (61.2 s effective) is over takt.
Lead time 9.6 days vs 223 s of value-added time → PCE 0.04 %.

In the chart-helper columns (O–Q), N/A values are deliberate — they keep unused steps off the takt line.
