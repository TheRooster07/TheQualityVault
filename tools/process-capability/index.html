Command line

Python needs the packages named on its download card; R uses base R. Both run the worked example with demo and accept your own CSV.

python process_capability.py demo
python process_capability.py --csv my_data.csv --column 0 --lsl 9.95 --usl 10.05 --subgroup-size 5 --save cap.png
Rscript process_capability.R            # runs the demo
// Worked example & method

What you'll get

Example (spec 10.00 ± 0.05 mm, subgroup size 5)

Index Value
Cp / Cpk 1.46 / 1.31
Pp / Ppk 1.30 / 1.17
Cpm 1.21
Expected PPM (overall) 237
Anderson-Darling p 0.767 (normal)
Verdict Marginal — reduce variation or re-centre

Method

σ within = MR-bar/1.128 (individuals) or R-bar/d2 (subgroups 2–10, complete subgroups only). σ overall = sample standard deviation. Anderson-Darling p-value per D'Agostino & Stephens (1986). Indices assume a stable, normally distributed process — check a control chart first.
