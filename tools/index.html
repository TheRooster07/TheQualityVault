Statistical Analysis

Parametric and non-parametric hypothesis tests, variance tests and regression.

Answer up to 8 questions and get the right statistical test (26 covered), its null hypothesis, assumptions, and the exact Excel, Python and R call. The Python and R scripts can also run the test.

 Parametric

1-Sample t-Test

Tests whether the mean of one sample differs from a target value mu0. t = (x̄ − mu0) / (s/√n), df = n − 1. Reports t, p-value and a confidence interval for the mean.

XLSXPYR
 Parametric

2-Sample t-Test

Compares the means of two independent samples. Reports both the pooled (equal variances) and the Welch (unequal variances) t-test with confidence intervals for the difference.

XLSXPYR
 Parametric

Paired t-Test

Tests whether the mean of paired differences (first − second) differs from a hypothesised difference (usually 0). Each row is one unit measured twice.

XLSXPYR
 Parametric

One-Way ANOVA

Tests whether the means of k groups are all equal (one factor). Reports the ANOVA table, R², pooled standard deviation and group confidence intervals. Python/R also print Tukey comparisons.

XLSXPYR
 Parametric

Two-Way ANOVA

Balanced two-factor ANOVA with interaction: tests factor A, factor B and A × B. Input is a long table: one row per observation with the A level, B level and response.

XLSXPYR
 Non-parametric

Mann-Whitney U

Rank-based test that two independent samples come from the same distribution (often read as 'equal medians'). Normal approximation with tie correction and continuity correction.

XLSXPYR
 Non-parametric

Wilcoxon Signed Rank

Tests whether the median of paired differences is zero (two columns) or whether one sample's median equals a target (one column). Zero differences are dropped; normal approximation with tie and continuity corrections.

XLSXPYR
 Non-parametric

Kruskal-Wallis

Rank-based test that k independent samples come from the same distribution (non-parametric one-way ANOVA). H statistic with tie correction, chi-square p-value.

XLSXPYR
 Non-parametric

Mood's Median Test

Counts how many values in each group lie above / at-or-below the grand median and runs a chi-square test on that table. Very robust to outliers.

XLSXPYR
 Counts & categories

Chi-Square Goodness of Fit

Tests whether observed counts in k categories match expected proportions (e.g. equal, or a historical mix). Reports chi-square, p-value and each category's contribution.

XLSXPYR
 Counts & categories

Chi-Square Test of Association

Tests independence in an r × c table of counts (e.g. defect type × shift). Reports chi-square, p-value, expected counts and how many cells have expected counts below 5.

XLSXPYR
 Counts & categories

Fisher's Exact Test

Exact test of association for a 2 × 2 table of counts. Use it instead of the chi-square test when counts are small (any expected count below 5). Reports two-sided and one-sided p-values and the odds ratio.

XLSXPYR
 Equal variances

Levene's Test

Tests whether 2 or more groups have equal variances. Brown-Forsythe version: one-way ANOVA on the absolute deviations from each group's median – robust to non-normal data.

XLSXPYR
 Equal variances

Bartlett's Test

Tests whether k normal populations have equal variances (more powerful than Levene when data are normal, but sensitive to non-normality).

XLSXPYR
 Equal variances

F-Test for Equal Variances

Tests whether two normal populations have the same variance. F = s1² / s2². Two-sided p-value and a confidence interval for the variance ratio.

XLSXPYR
 Regression

Regression

Ordinary least-squares regression of one response on 1–5 predictors: coefficients, standard errors, t and p-values, R², adjusted R², standard error of the regression and the model F-test.

Reliability Engineering

Life data analysis and failure prediction.

Weibull Analysis

2-parameter Weibull fit with suspensions (units still running): shape β, characteristic life η, B1/B10/B50 life, MTTF and reliability at a chosen time — by median rank regression (MRR) and maximum likelihood (MLE). Excel, Python and R give identical results.

XLSXPYR

Crow-AMSAA Reliability Growth

Tracks whether a design is getting more reliable as failures are found and fixed. Fits the Crow-AMSAA (power-law NHPP) model by maximum likelihood for one system or several identical systems: shape β, scale λ, bounds on β, Laplace trend test, instantaneous and cumulative MTBF, the test time needed to reach a target MTBF, and a forecast of further failures. Excel, Python and R give identical results.

XLSXPYR

Repairable Systems & Replacement Age

For a fleet of repairable units: how failures build up with age (mean cumulative function), whether units wear out (power-law NHPP fitted by maximum likelihood, with staggered start dates and retirements), which units fail far more than the rest (bad actors), the replacement age with the lowest long-run cost, and a keep / plan / replace recommendation for every unit still in service. Data can be entered as dates or ages. Excel, Python and R give identical results.
