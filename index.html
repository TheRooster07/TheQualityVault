// SPC Control Charts

Every chart type, built-in rules.

Western Electric, Nelson, and WECO rules with automatic signal detection. Variables and attribute data. Phase I and Phase II analysis.

X̄R
X-bar & R Chart
Subgroup means and ranges. Classic variables chart for subgroup data n=2–10.
 X̄S
X-bar & S Chart
Subgroup means and standard deviations. Preferred for larger subgroup sizes n>10.
 IMR
Individuals & MR Chart
Individual measurements with moving range. For continuous process data with n=1.
 EWMA
EWMA Chart
Exponentially weighted moving average. Detects small sustained process shifts.
 CUS
CUSUM Chart
Cumulative sum chart. Optimal for detecting small mean shifts with tabular method.
 p
p Chart
Proportion nonconforming. Attribute chart for variable subgroup sizes.
 np
np Chart
Number nonconforming. Attribute chart for constant subgroup size.
 u / c
u & c Charts
Defects per unit (u) and total defects (c) for count/Poisson data.
// Reliability Engineering

Life data analysis.
Failure prediction. FRACAS.

From accelerated life testing to fleet reliability growth — complete tooling for reliability practitioners.

01 / WEIBULL
Weibull Life Data Analysis
Fit 2 and 3-parameter Weibull distributions to failure data. Determine characteristic life, shape parameter β, scale parameter η, and B-life estimates.
MLE and Median Rank Regression fitting Confidence bounds (Fisher Matrix & Likelihood Ratio) B10 / B50 / BX life calculations Suspensions and interval censored data Probability, PDF, CDF, and Hazard plots
02 / CROW-AMSAA
Crow-AMSAA Reliability Growth
Track and project reliability growth during development and fielded systems. NHPP Power Law model with MLE parameter estimation and growth projection.
Time-terminated and failure-terminated tests Failure intensity and MTBF plots Laplace trend test for growth verification Projected MTBF at future time Multiple system fleet analysis
03 / FMEA & FTA
FMEA / Fault Tree Analysis
Design and Process FMEA with RPN and criticality matrix. Fault tree analysis with Boolean logic gates and minimal cut sets for system reliability.
AIAG/VDA FMEA format support Criticality analysis (MIL-STD-1629A) Qualitative and quantitative FTA Minimal cut set calculation
04 / FRACAS & RBD
FRACAS & System Reliability
Failure Reporting, Analysis and Corrective Action System template with Reliability Block Diagrams for series, parallel, and k-of-n configurations.
Closed-loop FRACAS workflow template Series, parallel, and complex RBD System MTBF / MTTF calculation Availability and maintainability modeling
